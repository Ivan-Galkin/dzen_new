# ИНСТРУКЦИЯ — «Изнанка эпох» (Дзен)

**Тип ниши:** factual (ведущий) + narrative (вторичный).
Это не проза и не лекция. Это фактическая объяснялка о бытовой изнанке истории, поданная сенсорно: через запах, звук, прикосновение, стыд. Читатель приходит за проверяемым фактом, но удерживается ощущением.

**Объём:** 4000–5500 знаков. Замер по топовым статьям канала-образца: 2522 / 4849 / 5116 / 5593. Короче 2500 не набирает, длиннее 6000 в этой нише не нужно.

**Площадка:** Дзен.

## Как пользоваться

Прикрепи три файла (ИНСТРУКЦИЯ + СТИЛЬ + СТРУКТУРА), дай тему, ИИ пишет статью.

## Процесс, 3 этапа

1. **КАРКАС.** По файлу СТРУКТУРА собери скелет под тему: крючок, 4–6 фактических блоков, финал с именем и цифрой.
2. **НАПИСАНИЕ.** По файлу СТИЛЬ пиши, соблюдая числа ритма и голос. Каждый абзац — один факт.
3. **ВЫЧИТКА.** Пройди чек-лист ниже, исправь, повтори до чистоты.

## Правила Дзена (критично)

- **Тире:** длинное `—` запрещено. Среднее `–` редко, максимум 3–5 на статью, для диапазонов. Вместо тире: запятая, точка, союз, двоеточие. Дефис только в составных словах.
- **Кавычки:** только «ёлочки».
- **Абзацы:** сплошной поток, без пустых строк между абзацами. Пустая строка только вокруг разделителя `***`.
- **Ритм живой:** не три коротких подряд, не два длинных подряд.
- **Антишлак:** однако→но, затем→потом, является→это, данный→этот, осуществлять→делать, «стоит отметить»→убрать, «в современном мире»→убрать.
- Не использовать конструкцию «Число. Число + контекст». Одно число не повторять три раза и больше.
- **Явность:** важный факт сказать прямо словами, не намёком. Читатель Дзена не перечитывает.
- **Монетизация (наследие narrative):** событие → реакция, без детальных описаний травм, смерти, насилия и медицинских подробностей. Телесность подаётся через быт и стыд, а не через физиологию. «Постыдный недуг короля» можно, описание симптомов нельзя.

> **Расхождение, о котором надо знать.** Канал-образец нарушает два правила из этого блока: ставит длинное тире 3–7 раз на статью и начинает с союзов только 5–7% предложений вместо предписанных 20–30%. При медиане 75 531 просмотр. Правила здесь сохранены как домашний стандарт, но если после первых 15 публикаций отдача окажется ниже ожидаемой, эти два пункта — первые кандидаты на пересмотр. Компромисс по союзам заложен в файле СТИЛЬ: 12–18%.

## Чек-лист вычитки (гейты)

- [ ] Крючок в первом предложении: сенсорная деталь + опровержение ожидания
- [ ] Ритм: короткие / средние / длинные ≈ **15 / 25 / 60 %**
- [ ] Средняя длина предложения 12–13 слов
- [ ] Абзац ≈ 190 знаков, 65% абзацев в 1–2 предложения
- [ ] Длинного тире нет; среднего максимум 3–5
- [ ] Кавычки только «ёлочки»
- [ ] Нет ИИ-штампов (антишлак пройден)
- [ ] Ключевые факты сказаны прямо
- [ ] **Гейт типа factual:** каждый фактический блок привязан к веку, стране или имени. Ни одного «историки считают» без указания, кто и когда
- [ ] **Гейт монетизации:** нет описаний травм, смерти, симптомов, физиологии
- [ ] Финал: конкретное имя + цифра или дата, а не обобщение
- [ ] Ни одного абзаца длиннее 4 предложений

## Заголовки

Используются формулы из файла `Карта-заголовков_worldlord.md`, секция 7–8, адаптированные под «Изнанку эпох». Ключевые ограничения, подтверждённые замером на 79 заголовках:

- **Максимум 8 слов, идеально 3–6.** За девятым словом медиана падает в пять раз (x0.20).
- **Телесная или бытовая конкретика обязательна.** Лифт x3.80.
- **Запрещено:** кавычки (x0.34), двоеточие (x0.61), числа, вопросительный и восклицательный знаки, слова «тайна», «правда», «скрывали», «шокирующий» (x0.47).
- **Не раскрывать финал.** Заголовок ставит сцену, а не пересказывает сюжет.
- **Не писать про деньги, политику и устройство государства** — худшие результаты канала-образца.
- **Правило узнаваемого якоря.** Каждый заголовок опирается на сущность, которую массовый читатель опознаёт без словаря. Не «Тюдоры», а «английские королевы». Не «ацтекские жрецы», а «жёны фараонов». Не «сенная девушка», а «служанка». Проверка: если человек, не открывавший учебник после школы, не может с ходу сказать, кто это, якорь не годится. В карте worldlord этот дефект стоил заголовку про Освальда Мосли 19 просмотров при медиане канала 75 531.
- Правило не отменяет экзотику, а задаёт вход в неё: самураи, гарем султана, наложницы, фараоны, Клеопатра, монголы, гейши, Древний Рим — да; ацтеки, шумеры, хетты, минойцы — нет.

**Рабочие формулы:**

1. `Чем пахли [знатные особы] до [появления блага]`
2. `Неприятные обязанности [придворная роль]`
3. `[Её/Их] [телесное проявление] слышал весь [место]`
4. `Как [народ] [гигиеническое действие] без [ресурса]`
5. `Их не считали за [категория людей]`
6. `[Стыдное прилагательное] недуг [титул]`
7. `Что [титул] оставлял в [интимное место]`
8. `[Число] поколений [женщин] [страшное повторение]`

**Приоритетный угол «Изнанки эпох».** У канала-образца неевропейские цивилизации дают лифт x1.70 при доле выпуска всего 9%. Рим, монголы, Япония, Персия, доколумбова Америка, Африка — та же механика стыда и телесности на почти неотработанном материале. Держать не меньше трети выпуска.
