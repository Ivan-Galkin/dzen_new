# ТЕСТ-16 для «Тётя Айгуль»: короткие заголовки (25.11.2026)

**Отменён до старта 25.11.2026:** вместо него `ТЕСТ-16_Формат-Вилки_2026-11-25.md` (решение владельца: неделю максимально похоже на «Вилку»).

Бриф от аналитика. Решение владельца 25.11.2026. Работай по файлам папки; ниже только то, что меняется.

## Зачем

Канал почти не показывается без стелл: CTR новых рассказов за двое суток 3–4%, в ретро-каналах 20–30%. Дочитывают из открывших 64–71%, значит, текст держит, а карточку не открывают. Проверяем, откроют ли чаще короткий заголовок.

## Задание

- С 26.11 заголовки рассказов по очереди: один **короткий**, один **обычный** (как сейчас по разделу 0 `Карта-заголовков.md`).
- **Короткий:** 6–9 слов, одно предложение, без второй фразы и без пересказа. Видны роль героини, обидчик и беда (пункты 1–4 раздела 0 остаются), финал не выдан. Тип Г или Н как обычно. Примеры вида: «Свекровь отдала мои ключи золовке», «"Квартира теперь общая", сказала свекровь при гостях».
- Пункт 5 раздела 0 (10–18 слов) для короткого не действует. Числа цифрами и прочие правила раздела 0 действуют.
- В колонку «Тип заголовка» таблицы `00_НАЧНИ-ОТСЮДА.md` писать «короткий Н», «короткий Г» или просто «Н», «Г».

## Что не менять

Всё остальное: темы, стоп-лист, формы, объём, обложки, общие правила (`ОБЩИЕ_ПРАВИЛА_РАССКАЗОВ.md`). Одна проверка на рассказ: другого теста на этих рассказах нет.

## Как публиковать (для владельца)

Как сейчас; короткие и обычные в разные часы, стеллы одинаково обоим.

## Как читаем результат

Короткие против обычных тех же дней (±2 дня), 8–10 пар: CTR за первые двое суток и открытия за 7 дней. Короткие лучше по CTR в 1,3 раза и больше при открытиях не ниже: короткий становится нормой. Ниже 0,8: вернуть обычные. Между: ещё 10 пар. Итог около 06.12 по дневным выгрузкам.
