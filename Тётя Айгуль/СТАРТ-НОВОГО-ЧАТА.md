# Как начать новый чат канала «Тётя Айгуль | Рецепты и истории»

## Шаги

1. Создать новую задачу в Claude, в проекте «Яндекс.Дзен». Компьютер не выбирать: всё хранится в GitHub, чат подключит репозиторий сам по тексту ниже.
2. Работать только в папке «Тётя Айгуль» репозитория; другие папки каналов не читать, чтобы правила не смешивались. Исключения: разбор сети Градова в `Аналитика/` и файл `Анастасия Лазурная/Закон-и-быт.md` для законов в рассказах наших дней (только для справки).
3. Уровень (Effort) High; для пачки статей Extra high.
4. Вставить первым сообщением текст ниже целиком и дождаться ответа.
5. Новый чат начинать примерно раз в 10–12 рассказов: рассказы длинные, чат быстрее сжимается.
