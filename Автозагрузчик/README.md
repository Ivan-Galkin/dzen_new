# Автозагрузчик черновиков Дзена

## Что можно запустить сейчас

Основной запуск — **Загрузить_в_Дзен.bat**. Сначала программа обрабатывает «Барскую волю», затем остальные каналы с заданным studio_url. Для семи каналов указаны адреса общего аккаунта. «Изнанка эпох» выключена. Браузер использует уже сохранённый профиль. Каждый материал сохраняется только в черновики.

№ 58 уже проверен в настоящей Студии. Теперь непосредственно в теле черновика остаются метки фотографий, исходные промпты и подписи на предусмотренных автором местах. Для простых рассказов применяется проверенный ввод по абзацам. Для форматированных статей программа помещает HTML в системный буфер обмена, вставляет его в редактор и сравнивает текст и оформление после обновления страницы. Это заменяет текущее содержимое буфера обмена.

## Установка на Windows

1. Нужны Git для Windows и Python 3.11 с Windows Python Launcher. Проверка в PowerShell — `git --version` и `py -3.11 --version`.
2. Получите модуль в папку проекта. В PowerShell выполните `git -C "C:\CLAUDE_Project\Дзен" pull --ff-only origin master` на локальной ветке master. При конфликте Git остановится. Сохраняйте имеющиеся локальные изменения.
3. В папке `C:\CLAUDE_Project\Дзен\Автозагрузчик` запустите **Установить_автозагрузчик.bat**. Он установит зависимости в отдельную среду и откроет Chromium. Войдите в Дзен сами и нажмите Enter в консоли для сохранения профиля. При запросе проверки пройдите её самостоятельно.
4. Запустите **Проверить_без_загрузки.bat**. Программа получит снимок GitHub в отдельный кеш, не переключая вашу ветку и не затрагивая файлы авторов. Ошибка сети после повторной попытки остановит запуск. Консоль останется открытой.
5. Откройте `%LOCALAPPDATA%\DzenDraftLoader\last-report.txt`. В отчёте перечислены номера, заголовки, причины проверки и найденные заглушки. Превью находится в `preview\<id канала>\<номер>.html`, промпты и ориентиры — в `images\<id канала>\<номер>.json`. Превью открывается и копируется как форматированный текст. Рабочий BAT проверяет результат после обновления страницы в самом редакторе.

| Источник | Правило |

| Тётя Айгуль | Сквозные номера и пути берутся из ВЫКЛАДКА.md до первой неготовой строки. Строки со статусом «резерв снят» пропускаются. С №45 файл называется Публикация-NN_ГОТОВО-К-ВСТАВКЕ.md, где NN совпадает с номером в таблице. Файлы вне таблицы не сканируются. Пустое «Вышло» означает неизвестный статус. |

Форматирование результата можно проверить на HTML. Если редактор Дзена потеряет таблицу или разделитель при вставке, проверка пилота должна это обнаружить. Markdown исходника сохраняется. Любой неизвестный формат требует проверки до включения записи.

## Настройки и журнал

Установщик один раз копирует config.example.json в `%LOCALAPPDATA%\DzenDraftLoader\config.json`. Новый канал с уже поддерживаемым форматом подключается строкой в массиве channels. Поля id и folder определяют постоянную идентичность канала и папку. name — отображаемое имя, source — stories, history, queue или marketing, profile — локальный профиль аккаунта. При смене отображаемого имени сохраните id.

Для второго аккаунта задайте другой profile в настройках, затем выполните в PowerShell из папки модуля:

```powershell
& "$env:LOCALAPPDATA\DzenDraftLoader\venv\Scripts\python.exe" main.py login --profile second
```

База publications.sqlite, технический журнал, браузерные профили и кеш лежат под %LOCALAPPDATA%\DzenDraftLoader. Для переноса журнала закройте программу и сделайте резервную копию базы. Потеря базы требует новой первоначальной сверки. Одновременный запуск блокируется на уровне SQLite.

## Первый рабочий запуск

1. Запустите **Загрузить_в_Дзен.bat**. Если появится просьба показать кнопку создания, один раз нажмите **+** в окне Студии. Пункт **«Написать статью»** выберет программа. Если оформление кнопки изменится, она может запросить этот шаг повторно.
2. При первом рабочем запуске программа запоминает готовые номера в GitHub. Следующие запуски находят новые готовые номера по каждому каналу. Редактирование старого рассказа сохраняет его номер. Программа использует прежний журнал при обновлении.
3. Для нового материала программа открывает меню канала и нажимает «Написать статью». После загрузки полей запоминает адрес этого черновика, вводит текст и проверяет его после обновления. Список публикаций прокручивать не требуется.
4. Если ввод прервался и адрес известен, следующий запуск вернётся к тому же черновику. Если сбой случился до записи адреса, следующая попытка откроет новый черновик. Предыдущий пустой черновик может остаться в Студии.

Адрес нового канала задаётся полем studio_url (например, https://dzen.ru/profile/editor/barskaya_volya). Для отключения канала задайте enabled равным false. Если название в Студии отличается от названия в настройках, используйте studio_name. Отсутствующий в прежней локальной конфигурации адрес для штатного канала подхватывается из config.example.json.

Официальный текст условий Дзена на этапе разработки проверить не удалось. [Условия сервиса](https://dzen.ru/legal/ru/termsofuse/).

## Тесты

Из папки модуля выполните:

```powershell
& "$env:LOCALAPPDATA\DzenDraftLoader\venv\Scripts\python.exe" -m unittest discover -s tests -v
```

Тесты читают фактические исходники из родительской папки. Для проверки отдельного снимка можно задать DZEN_TEST_SOURCE. Чтобы запустить диагностику этого снимка без обращения к GitHub, используйте `main.py check --snapshot ПУТЬ --state ВРЕМЕННАЯ_ПАПКА`. Используйте отдельную временную папку состояния для тестов.
