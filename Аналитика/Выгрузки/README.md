# Выгрузки Студии Дзена

Порядок с 16.11.2026 (решение владельца): одна папка на канал, внутри все выгрузки «по времени события» по одному дню.

- `Свои и чужие/`, `Общая кухня/`, `Маменька велела/` (и так же для новых каналов: `Анастасия Лазурная/`, `Тётя Айгуль/`, `Барская воля/`).
- В папке канала файлы как их отдаёт Студия: `dzen_stat_ГГГГ-ММ-ДД_ГГГГ-ММ-ДД.xlsx`, один файл на день. Если Студия дописала « (1)», можно не переименовывать: аналитик читает канал и дату из шапки файла.
- `периоды/`: выгрузки за несколько дней (месяц, неделя).
- `ранние выгрузки/`: тот же день, выгруженный раньше и неполный (Дзен ещё досчитывал); основная версия лежит в папке канала.
- Чужие каналы для разборов отдельными папками: `2026-11-11_Вилка/`, `2026-11-11_ЖЖИ/`.

Последний день в выгрузке почти всегда неполный: выгружать день не раньше чем через сутки, лучше через двое.
