# Как начать новый чат канала «Digital Ivan. Маркетинг без лапши»

## Шаги

1. Создать новую задачу в Claude, в проекте «Яндекс.Дзен». Компьютер не выбирать: всё хранится в GitHub.
2. Работать только в папке «Маркетинг без лапши». Папки каналов рассказов не читать: там другие правила.
3. Вставить первым сообщением текст ниже целиком.

## Текст первого сообщения (скопировать целиком)

```
Это чат моего экспертного Дзен-канала «Digital Ivan. Маркетинг без лапши»: статьи от первого лица для собственников и руководителей бизнеса о рекламе, SEO, аналитике и проверке подрядчиков. Все файлы канала в папке «Маркетинг без лапши». Отвечай по-русски.

1. Подключи репозиторий GitHub Ivan-Galkin/dzen_new (ветка master) с доступом на запись и склонируй его. Если не получается, скажи мне и дальше не продолжай.
2. Прочитай в папке «Маркетинг без лапши»: 00_НАЧНИ-ОТСЮДА.md и все файлы из его раздела «Что прочитать перед работой», плюс 03_Сборщик-системы.md в корне. Другие папки каналов не читай.
3. Коротко подтверди, что понял (3–5 строк: что готово, какие хвосты), и задай следующие 1–2 вопроса из Вопросы.md.

Дальше: я надиктовываю голосом, ты записываешь ответ в Банк-опыта.md, показываешь коротко, что записал, предлагаешь темы и задаёшь следующие вопросы. Статьи пишешь в папку Статьи/. После каждого шага коммит «Маркетинг без лапши: …» и git push в master.
```
