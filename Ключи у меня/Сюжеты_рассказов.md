# Сюжеты рассказов «Ключи у меня»

## Приёмы, которые нельзя повторять подряд

- Документ на стол как развязка (не чаще одного из двух).
- Смена замков; чемодан у двери (каждое не чаще одного из трёх).
- Свекровь говорит «деточка» (не чаще одного из трёх).
- Запись разговора как улика (не чаще одного из пяти, и только своя законная).
- Ремесло героини: одно ремесло не в пяти рассказах подряд.
- Тайный союзник из семьи обидчика; свидетель из-за двери; ребёнок проговаривается (каждое не подряд).
- Юбилей как место публичной сцены (не два подряд: есть загс, нотариус, родительское собрание, свадьба, приёмная, собрание жильцов, дача).
